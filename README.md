# 弾む思いつき (Hazumu Omoitsuki)

**深海物理ピンボール × デッキ構築（シナジービルド）ブラウザゲーム**

外部ライブラリ・外部音声ファイルを使用せず、素の HTML / CSS / JavaScript + Canvas 2D + Web Audio API シンセサイザーで実装された物理ピンボールゲームです。  
公開URL：[https://shinpoyo.com/pinball-deckbuilder/](https://shinpoyo.com/pinball-deckbuilder/)

## 遊び方

1. **ノルマ達成でラウンドクリア**：発光する真珠ボールを打ち出し、各ラウンド3球以内に目標スコア（ノルマ）を達成するとクリア。全8ラウンド（R8「深海の主」戦）制覇を目指します。クリア後は「海溝エンドレスモード（R9〜）」も解放されます。
2. **カードドラフト＆10スロット配置**：ラウンドクリアごとに3枚のカードから1枚を選び（各ラウンド1回リロール可能）、盤面の10か所の配置スロットに深海パーツを設置・強化（最大Lv3）します。
   - **配置パーツ（9種）**：真珠貝（丸バンパー）、枝珊瑚（三角バンパー）、熱水噴出孔（キッカー）、海流の渦（スピナー）、岩礁（リバウンド壁）、渦潮（ワープゲート）、起爆ウニ（連鎖起爆）、蓄電クラゲ（充電放出）、分裂クラゲ（ミニボール生成）
   - **ボールカード（3種）**：重真珠（スコアUP）、泡玉（低重力＆高反発）、発光玉（魚回収範囲＆魚スコアUP）
   - **強化・即時カード（4種）**：深海結晶（パーツ強化）、追加真珠（追加ボール）、海神の祝福（スコアブースター）、海流フィン強化（フリッパー強化）
3. **構築シナジー（6種）**：盤面のパーツ構成に応じて、**珊瑚礁の楽園・湧昇流サイクル・深海大循環・海底の迷宮礁・深淵の熟成・豊かなる生態系** の6種類のシナジーボーナスが自動発動します。
4. **深海魚コレクション＆パッシブ効果**：盤面を泳ぐ全12種の深海魚にボールを当てて回収すると図鑑に登録され、集めた魚の種類に応じてそのラン中、5系統のパッシブ効果（**発光・群れ・守り・大物・俊敏**）が発動します。
5. **ラウンドごとの海域ルール（R1〜R8）**：R2「海流」、R3「魚群」、R4「満潮」、R5「低重力」、R6「コンボ持続」、R7「大漁」、R8「深海の主＋海流」と、ラウンドごとに異なる環境変化が発生します。
6. **ピンボールギミック**：SKILL SHOT、BALL SAVE、上部ロールオーバー＆JACKPOT、FEVER TIME、アウトレーン・キックバックなど。

## 操作方法

- **左右フリッパー**：`←` / `→` キー（または `Z` / `/`、`A` / `D`）、画面下部ボタン、タッチ操作
- **プランジャー発射**：`Space` または `↓` キー長押しで溜めて離す（タッチは `LAUNCH` ボタン長押し）
- **海流揺らし（ナッジ）**：`Shift` / `X` / `↑` キー、または上部HUDの「🌊揺らす」ボタン（揺らしすぎると `TILT` 警告）
- **ポーズ・ビルド＆魚効果確認**：`P` / `Esc` キー、または上部HUDの「⏸」ボタン

## ファイル構成

ビルド不要の静的ファイル構成です。

```text
index.html        # エントリーポイント（HTML・メタタグ/OGP）
assets/style.css  # スタイルシート
assets/game.js    # ゲーム本体（物理演算・Canvas描画・Web Audio）
assets/img/       # 外部WebP画像25枚・SVGファビコン・OGP画像
```
