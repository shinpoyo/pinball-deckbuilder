# 弾む思いつき (Hazumu Omoitsuki)

**深海物理ピンボール × デッキ構築（シナジービルド）ブラウザゲーム**

外部ライブラリ・外部音声ファイルを使用せず、素の HTML / CSS / JavaScript + Canvas 2D + Web Audio API シンセサイザーで実装された物理ピンボールゲームです（`index.html`、`assets/style.css`、`assets/game.js`、`assets/img/*.webp` の静的ファイル構成でビルド不要）。

## 遊び方

1. **ノルマ達成でラウンドクリア**：各ラウンド3ボール以内に目標スコア（ノルマ）を達成するとラウンドクリアとなり、全8ラウンド（R8ボス）制覇を目指します。
2. **カードドラフト＆10スロット配置**：ラウンドクリアごとに3枚のカードから1枚を選び（各ラウンド1回リロール可能）、盤面の10か所の配置スロットにパーツを設置・強化（最大Lv3）します。
3. **構築シナジー**：盤面のパーツの組み合わせに応じて6種類のシナジーボーナス（バンパー王国、永久機関、次元跳躍、反射迷宮、匠の極致、百花繚乱）が自動発動します。
4. **ピンボールギミック**：
   - **SKILL SHOT**：発射後4.5秒以内に点滅しているターゲットパーツに当てるとボーナス獲得
   - **BALL SAVE**：発射直後の即落ちを防ぐレーザーバリア
   - **I-D-E ロールオーバー＆JACKPOT**：上部3レーン点灯で中央セーフティポスト出現＆移動JACKPOTターゲット出現
   - **FEVER TIME**：左右4か所の壁ターゲット点灯で10秒間スコア1.25倍

## 操作方法

- **左右フリッパー**：`←` / `→` キー（または `Z` / `/`、`A` / `D`）、画面下部ボタン、タッチ操作
- **プランジャー発射**：`Space` または `↓` キー長押しで溜めて離す（タッチは `LAUNCH` ボタン長押し）
- **台揺らし（ナッジ）**：`Shift` / `X` / `↑` キー、または上部HUDの「💥揺らす」ボタン（揺らしすぎると `TILT` 警告）
- **ポーズ・ビルド確認**：`P` / `Esc` キー、または上部HUDの「⏸」ボタン
