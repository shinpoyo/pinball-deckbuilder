# 指示書：『弾む思いつき』変化と発見の強化（合成進化・封印大貝・クセ強ボール・オーバーキル）

対象ファイル: `index.html`, `assets/style.css`, `assets/game.js`
目的: 「単調で変化が少ない」「これをするとどうなるんだろうが無い」を解消するため、配置・物理・ハプニング・欲張りの4方向から予想外の体験を追加する。

## 1. パーツ合成進化（化学反応6種）
- 配置フェーズで特定の別種パーツ同士を重ねると、変異パーツへ進化する（ドラフトカードに `⚗ 合成進化可能!` バッジ、配置盤面に桃枠 `⚗合成!` 表示）。
- 6種のレシピ（初回発見は `hazumu_omoitsuki_fusion_zukan_v1` に保存）：
  - 起爆ウニ × 分裂クラゲ → **爆裂クラゲ**（2ヒットで周囲起爆＋ミニボール3球射出）
  - 真珠貝 × 渦潮 → **重力真珠**（周囲のボールを重力吸引→高反発）
  - 蓄電クラゲ × 熱水噴出孔 → **雷流噴出孔**（高速打ち上げ＋2ヒットごとに他パーツ2個へ雷撃連鎖）
  - 枝珊瑚 × 海流の渦 → **竜巻珊瑚**（高速回転で周囲の深海魚を吸引＋コンボ+2）
  - 岩礁 × 起爆ウニ → **鏡面機雷**（反射で隣接起爆＋6秒間スコア+20%オーラ最大3重）
  - 蓄電クラゲ × 分裂クラゲ → **放電プリズム**（充電解放でミニボール2球＋周囲起爆）

## 2. 盤面の「封印された大貝（Mystery Shell）」＆深海ハプニング5種
- 各ラウンド盤面に3ヒットで開封できる `???` の封印大貝が出現（最大2回/ラウンド）。
- 開封すると5種のハプニング（マルチボール暴走 / 重力反転8秒 / 全パーツ一斉起爆 / 深海魚大群ラッシュ / 巨大真珠タイム10秒）のいずれかが発動。

## 3. クセ強ボールカード2種追加
- **分裂真珠**（パーツ4ヒットごとにミニボール自動分裂）
- **磁石真珠**（近くの深海魚・封印大貝・ジャックポットへ磁力カーブ吸引）

## 4. ノルマ達成後の「オーバーキル（欲張りタイム）」
- ノルマ達成時に即終了せず、6秒間の `OVERKILL ×1.5` モードへ突入（「次へ ⏭」ボタンで即時スキップ可）。
- 150%達成で次ドラフトの `🎲リロール+1` を獲得。オーバーキル中の落下は残機を減らさずクリア遷移。
